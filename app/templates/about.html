About FraudGuard

AI-Powered Chargeback and Fraud Risk Scorer

🎯 Problem We Solve

Merchants lose millions every year to fraudulent transactions and chargebacks. Traditional rule-based systems miss sophisticated fraud patterns and generate too many false alarms. FraudGuard uses Machine Learning to score every transaction in real time — catching fraud before it causes damage.

⚙️ How It Works
1
Upload CSV

Merchant uploads transaction data as a CSV file

2
AI Scores Each Row

Random Forest model assigns fraud probability to each transaction

3
Risk Dashboard

Results shown as High, Medium, Low risk with full metrics

🧠 ML Pipeline
  1. Load Credit Card Fraud dataset (284,807 transactions)
  2. Drop Time column, scale Amount using StandardScaler
  3. Handle class imbalance using SMOTE oversampling
  4. Train Random Forest Classifier (100 trees, balanced weights)
  5. Evaluate on stratified 80/20 test split
  6. Save model and scaler using Joblib
  7. Score new transactions via Flask web interface
